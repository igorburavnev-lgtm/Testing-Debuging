## Что сделано

Написаны тесты по спецификации для всех четырёх проектов. Тесты были
написаны сначала по описанию методов, потом запущены — часть упала,

Запуск:

    cd 01-TextTools && dotnet test
    cd ../02-GradeBook && dotnet test
    cd ../03-Cart && dotnet test
    cd ../04-DateRange && dotnet test

### 01-TextTools

| Метод | Вход | Ожидалось | Получилось | Причина |
|---|---|---|---|---|
| `CountWords` | `""` | 0 | 1 | `Split(' ')` на пустой строке даёт массив из одного элемента |
| `CountWords` | `"раз  два"` | 2 | 3 | пустая строка между двойными пробелами считается словом |

| `Truncate` | `("абвгде", 5)` | `"аб..."` (длина 5) | `"абвгде..."` (длина 9) | три точки добавляются поверх `maxLength` символов |

## Починка

Правки внесены в `src/*/*.cs`:

- **TextTools** — `Split` с массивом разделителей и `RemoveEmptyEntries`;
  `Truncate` резервирует три символа под `...`; `IsPalindrome` убирает
  пробелы; `MaskCard` проверяет длину.
- **GradeBook** — приведение к `double` перед делением; `Max`
  инициализируется первым элементом; `Median` работает с копией;
  `TopN` берёт `Math.Min(n, Count)`.
- **Cart** — `100m` вместо `100` (делить на `decimal`); проверка диапазона
  скидки; `>=` для порога доставки; `MidpointRounding.AwayFromZero`
  для округления; `Cheapest` проверяет пустую корзину.
- **DateRange** — `+1` в `Days`; `<=` в `Overlaps`; исключение субботы
  и воскресенья; коррекция возраста; полное правило високосного года.

После починки все тесты проходят зелёным.
