# 02 · GradeBook — числа и списки

Журнал оценок: среднее, максимум, медиана, подсчёт по порогу,
топ-N и перевод в буквенную оценку.

```
dotnet test                 # запустить все тесты этого проекта
dotnet test --list-tests    # только имена, ничего не запускается
```

Сейчас в проекте семь зелёных теста-примера — запустите и убедитесь,
что сборка работает. Общая инструкция и справка по xUnit — в `README.md`
в корне архива.

## Где что лежит

```
02-GradeBook/
  GradeBook.sln
  src/GradeBook/GradeBook.cs            <- код с багами, здесь же спецификация
  tests/GradeBook.Tests/GradeBookTests.cs   <- ваши тесты, здесь же примеры
```

## Что покрыть тестами

| Метод | Что должен делать |
|---|---|
| `Average` | среднее арифметическое, без округления |
| `Max` | наибольшая оценка |
| `Median` | значение в середине отсортированного списка |
| `CountAbove` | сколько оценок строго больше порога |
| `TopN` | первые N самых больших, по убыванию |
| `Letter` | 5 → A, 4 → B, 3 → C, остальное → F |

Часть этих методов работает неправильно. Сколько именно — не скажу.

## Спецификация — в комментариях

Над каждым методом в `src/GradeBook/GradeBook.cs` написано, что он **обязан**
делать, с примерами. Пишите тесты **по этому описанию**, а не по тому,
что код делает сейчас. Иначе тест просто закрепит баг.

## На что смотреть в первую очередь

- **Целочисленное деление.** В C# `9 / 2` это `4`, а не `4.5`.
  Среднее от 4 и 5 — самый короткий тест в этом проекте.
- **Пустой список.** Спецификация обещает конкретное исключение.
  `Assert.Throws` требует точный тип: если обещан `ArgumentException`,
  а приходит `DivideByZeroException` — это баг.
- **Все оценки отрицательные.** Классическая ловушка `int max = 0`.
- **Чётное и нечётное количество** элементов для медианы.
- **Запросили больше, чем есть:** топ-5 из списка в один элемент.
- **Метод не должен портить входной список.** Для `Median` и `TopN`
  это записано в спецификации прямо — значит, проверяется тестом.
