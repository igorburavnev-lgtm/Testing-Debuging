# 01 · TextTools — работа со строками

Шесть функций для текста: подсчёт слов, обрезка, заглавная буква,
палиндром, маска номера карты, повтор с разделителем.

```
dotnet test                 # запустить все тесты этого проекта
dotnet test --list-tests    # только имена, ничего не запускается
```

Сейчас в проекте четыре зелёных теста-примера — запустите и убедитесь,
что сборка работает. Общая инструкция и справка по xUnit — в `README.md`
в корне архива.

## Где что лежит

```
01-TextTools/
  TextTools.sln
  src/TextTools/TextTools.cs            <- код с багами, здесь же спецификация
  tests/TextTools.Tests/TextToolsTests.cs   <- ваши тесты, здесь же примеры
```

## Что покрыть тестами

| Метод | Что должен делать |
|---|---|
| `CountWords` | сколько слов в тексте |
| `Truncate` | укоротить текст до N символов, добавив `...` |
| `Capitalize` | первая буква заглавная, остальные строчные |
| `IsPalindrome` | читается ли одинаково в обе стороны |
| `MaskCard` | спрятать номер карты, кроме последних четырёх цифр |
| `RepeatJoin` | повторить слово N раз через разделитель |

Часть этих методов работает неправильно. Сколько именно — не скажу.

## Спецификация — в комментариях

Над каждым методом в `src/TextTools/TextTools.cs` написано, что он **обязан**
делать, с примерами. Пишите тесты **по этому описанию**, а не по тому,
что код делает сейчас. Иначе тест просто закрепит баг.

## На что смотреть в первую очередь

- **Пустая строка и строка из одних пробелов.** Что должен вернуть
  подсчёт слов для `""`? А для `"   "`?
- **Двойные пробелы, табуляция, перевод строки** между словами.
- **Длина результата обрезки.** Спецификация обещает, что результат
  не длиннее заданного предела. Проверьте `.Length`, а не только текст.
- **Строка ровно по длине предела**, а потом на один символ короче
  и на один длиннее.
- **Палиндром с пробелами** — например, `"а роза упала на лапу азора"`.
- **Номер карты короче четырёх цифр.** Что должно произойти?

## Как записать найденное

```
01-TextTools / Truncate
  вход:        text = "абвгде", maxLength = 5
  ожидалось:   "аб..." (длина 5)
  получилось:  "абвгд..." (длина 8)
  тест:        Truncate_LongerThanLimit_ResultFitsLimit
```
