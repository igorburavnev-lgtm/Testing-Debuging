# 04 · DateRange — даты и интервалы

Длина интервала, пересечение интервалов, рабочие дни, возраст,
високосный год, ближайший понедельник, запись интервала строкой.

```
dotnet test                 # запустить все тесты этого проекта
dotnet test --list-tests    # только имена, ничего не запускается
```

Сейчас в проекте два зелёных теста-примера — запустите и убедитесь,
что сборка работает. Общая инструкция и справка по xUnit — в `README.md`
в корне архива.

## Где что лежит

```
04-DateRange/
  DateRange.sln
  src/DateRange/DateRange.cs            <- код с багами, здесь же спецификация
  tests/DateRange.Tests/DateRangeTests.cs   <- ваши тесты, здесь же примеры
```

## Что покрыть тестами

| Метод | Что должен делать |
|---|---|
| `Days` | дней в интервале, **включая оба конца** |
| `Overlaps` | пересекаются ли два интервала |
| `WorkDays` | рабочих дней в интервале (пн–пт) |
| `Age` | полных лет на дату |
| `IsLeap` | високосный ли год |
| `NextMonday` | ближайший понедельник после даты |
| `Format` | `"дд.ММ.гггг - дд.ММ.гггг"` |

Часть этих методов работает неправильно. Сколько именно — не скажу.

## Спецификация — в комментариях

Над каждым методом в `src/DateRange/DateRange.cs` написано, что он **обязан**
делать, с примерами. Пишите тесты **по этому описанию**, а не по тому,
что код делает сейчас. Иначе тест просто закрепит баг.

## На что смотреть в первую очередь

- **Интервал из одного дня.** Начало и конец совпадают.
  Спецификация говорит «включительно с обоих концов» — значит, 1.
- **Интервалы, которые соприкасаются одним днём.** 1–5 марта
  и 5–9 марта: общий день есть, значит пересекаются.
- **Интервалы с разрывом ровно в один день:** 1–5 и 6–9.
- **Суббота отдельно от воскресенья.** Возьмите неделю
  с понедельника по воскресенье: рабочих дней должно быть 5.
- **День до дня рождения, сам день рождения, день после.**
- **Годы 1900 и 2000.** Оба делятся на 4, но високосный только один.
  Правило: делится на 4 и не делится на 100, либо делится на 400.
- В тестовом файле есть подсказка по календарю марта 2026:
  2-е — понедельник, 7-е — суббота, 8-е — воскресенье.

## Как записать найденное

```

  ожидалось:   1 (один день, включительно)
  получилось:  0
  тест:        Days_SameDay_ReturnsOne
```
